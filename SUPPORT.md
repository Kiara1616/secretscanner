# Support

- Use [GitHub Discussions](https://github.com/Kiara1616/secretscanner/discussions) for usage questions and ideas.
- Use the [bug report form](https://github.com/Kiara1616/secretscanner/issues/new?template=bug_report.yml) for reproducible defects.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Please include your operating system, Python version, SecretScanner version, command and sanitized output. Never include real secrets.
